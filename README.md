# DSC180A-Methodology-4

Ryan Lindberg's Methodology Assignment 4, Part 2.

This site uses Jekyll and the Cayman theme on GitHub Pages.

- `index.md` contains the four reflection responses.
- `_config.yml` sets the site title, URL, and theme.
- `.gitignore` limits the public repository to the website files.

## Publishing

In Settings > Pages, choose **Deploy from a branch**, select **main** and
**/ (root)**, and save. GitHub builds the Markdown with Jekyll.

Expected website URL after deployment:
https://lindbergryan04.github.io/DSC180A-Methodology-4/

## Submission

Review the reflection responses, verify that the public website renders,
then submit its URL and `index.md` to Task 2 on Gradescope.
